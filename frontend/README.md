
# Petrol Bunk Management Software - Frontend

Frontend application for the Petrol Bunk Management Software suite.

## Overview

This project is the frontend interface for managing petrol bunk operations, including sales, inventory, pump monitoring, staff management, and reporting.

## Features

- Dashboard for quick access to key metrics
- Fuel sales entry and transaction management
- Stock and inventory tracking
- Pump status monitoring
- User and role management
- Reports and analytics

## Tech Stack

- JavaScript / TypeScript
- Frontend framework/library (React)
- CSS / SCSS
- API integration with backend services

## Getting Started

1. Clone the repository
   ```bash
   git clone <repository-url>
   cd frontend
   ```

2. Install dependencies
   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

3. Start the development server
   ```bash
   npm start
   ```

   or

   ```bash
   yarn start
   ```

4. Open the app in your browser:
   ```
   http://localhost:3000
   ```

## Available Scripts

- `npm start` / `yarn start` - Run the app in development mode
- `npm run build` / `yarn build` - Build the app for production
- `npm test` / `yarn test` - Run the test suite
- `npm run lint` / `yarn lint` - Run linter checks (if configured)

## Environment Variables

Create a `.env` file in the `frontend` folder with required variables:

```env
REACT_APP_API_URL=http://localhost:5000
# Add additional env variables as needed
```

## Folder Structure

- `src/` - source code
- `public/` - static assets
